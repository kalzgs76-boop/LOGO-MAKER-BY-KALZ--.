# LOGO MAKER BY KALZ — Proyek Android

Ini adalah proyek Android Studio native (Kotlin), bukan aplikasi HTML.

## Cara membuat APK
1. Ekstrak ZIP ini.
2. Buka Android Studio.
3. Pilih **Open** lalu pilih folder `LOGO_MAKER_BY_KALZ_Android`.
4. Tunggu Gradle Sync selesai. Pastikan Android SDK Platform 35 terpasang.
5. Pilih **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
6. APK hasil build biasanya ada di `app/build/outputs/apk/debug/app-debug.apk`.

## Fitur versi 1.0
- Editor logo berbasis teks.
- Pilihan font dan warna.
- Efek cahaya, bayangan, dan teks miring.
- Bingkai perisai, lingkaran, hexagon, atau tanpa bingkai.
- Simpan logo PNG ke folder Pictures/LogoMakerByKalz.
- Bekerja offline setelah terpasang.

## Catatan
- `compileSdk 35` dan Android Gradle Plugin 8.7.3 digunakan.
- Android Studio/Gradle akan mengunduh komponen build yang diperlukan saat sinkronisasi pertama.
